
# arraylib

Кроссплатформенная динамическая библиотека операций над массивами целых чисел.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск приложения

```bash
./build/app
```

## Запуск тестов

```bash
cd build && ctest --output-on-failure
```
